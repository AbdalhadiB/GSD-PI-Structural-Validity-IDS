## نتائج التحقق

- تم التحقق من البنية والتخزين بصيغة ZIP، وفك المكونات، وصحة دفتر Jupyter الأساسي والدفاتر الخمسة الداعمة.
- **6 دفاتر منفذة** في الحزمة؛ لا توجد أخطاء تشغيل محفوظة في مخرجاتها. هذا لا يثبت نجاح إعادة التنفيذ في بيئة جديدة.
- تحقق حسابي من TP/FP/FN وPrecision وRecall وLift للمجموعتين الرئيسيتين.
- فترات M5 والإحصاءات المتاحة متسقة في أعدادها مع مخرجات Algorithm 1.
- مجموع مراحل D7 = **354.586 ثانية**؛ أعلى RSS للعملية = **0.452 GiB**، لقياس واحد فقط.
- تحققت سلامة بصمات SHA-256 للمحتويات بعد التجميع.
- حذفت/حجبت عناوين IP من مخرجات العرض في دفتر WTMC العام، ولم تتغير الشيفرة أو الأرقام.
- لا يتضمن الملف المجمع سجلات إنتاج HTTPS أو مفاتيح API أو جدولَي `private_source_flags.csv`.

ملف Algorithm 1 v2 يستخدم `P95_REFERENCE_WEAK` في CSE-CIC، بينما دفتر D7 الأقدم يستعمل `P95_STABLE`، واختبار حساسية M4 المخصص لمخرجات المرشحين الأقوياء يُصدر عددًا صفريًا عند `WEAK_ISOLATION`. الحساب البنيوي واحد تقريبًا لكن عقدة القرار ودلالة `selected` ليست متطابقة. تم توثيقها بوضوح بدل تعديل تاريخية الأدلة.

## عناصر غير مكتملة

1. **تمت إضافة M4 OAT:** أُدرج ملف CSV الذي رفعه المؤلف دون تعديل (46 اختبارًا) واستعيد السكربت من نصه في مكتبة المشروع (99 سطرًا). تطابق ملف Python بايتًا مع نسخته الأصلية لم يُثبت؛ لم يُعد التشغيل على المدخلات الأصلية.
2. لم تُدرج ملفات `entity_table` الأصلية ولا بصماتها/سلسلة إنتاجها؛ لذلك لا تدعي الحزمة إعادة إنتاج كاملة من بيانات التدفقات الخام.
3. لا تزال بعض تحفظات التحكيم قائمة، ومنها غياب عينة AbuseIPDB تمثيلية خارج الذيل، والحدود الإحصائية والمشكلات القانونية/المؤسسية المنفصلة.
4. لا يوجد DOI أو GitHub Release حتى الآن؛ يلزم قرار المؤلف بشأن الترخيص والاعتمادات قبل النشر.
